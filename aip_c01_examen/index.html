AIP-C01 Exam-Prep Course

A ruthlessly exam-focused study course for the AWS Certified Generative AI Developer – Professional (AIP-C01) certification. English. ~40 hours over 8 weeks (5h/week), weighted hard toward Domains 1 & 2 (57% of the exam).

The course is written in Markdown. GitHub renders it natively, so the links below open the files on github.com. Start with the strategy plan, memorize the decision tables, then rehearse with the question bank and final mock.
