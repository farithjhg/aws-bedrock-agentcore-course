A **differentiated base layer** for the **AWS Certified Generative AI Developer – Professional (AIP-C01)** exam. It gives you only what the official prep does not: decision discriminators (which service and *why not* the near-neighbor), single-axis service contrasts, the traps and qualifier-flips, and original scenario practice. It assumes you already know what RAG, embeddings, agents, and Guardrails *are*.

This is **not** a replacement for the AWS exam guide or Skill Builder's official practice set — run those in parallel.

Honest framing: AIP-C01 is Professional-tier. You are starting from a basic base at ~**5h/week**, Oct 21 → **Dec 15, 2026** — a genuine **stretch goal**. A built-in **readiness gate** around Dec 8 tells you plainly whether to sit or reschedule ([final mock](/practica/simulacro-final)).

## Exam at a glance

| Attribute | Value |
|---|---|
| Exam code / level | AIP-C01 / Professional |
| Questions | 75 (65 scored + 10 unscored pretest) |
| Time | 180 min (~2.4 min/question) |
| Cost | `$300 USD` *(confirm current price at registration)* |
| Pass | 750 on a 100–1,000 scaled range |
| Scoring | Compensatory (no per-domain minimum) |
| Question types | Multiple choice (1 of 4); multiple response (2+ of 5+, all required, no partial credit) |
| Blank answers | Count as incorrect; no guessing penalty |

Full mechanics and scenario-reading discipline: [exam strategy](/blueprint/vision-examen).

## How to use this course

1. **Start with the [8-week plan](/plan-estrategico)** — it drives everything.
2. **Memorize the decision tables** — [by constraint (master)](/tablas-decision/decision-por-restriccion), [vector stores](/tablas-decision/decision-vector-stores), [deployment modes](/tablas-decision/decision-despliegue).
3. **Read the blueprints as cheat sheets** — [D1](/blueprint/dominio-1-fundacion-datos), [D2](/blueprint/dominio-2-implementacion), [D3](/blueprint/dominio-3-seguridad), [D4](/blueprint/dominio-4-optimizacion), [D5](/blueprint/dominio-5-testing).
4. **Rehearse** — [question bank](/practica/banco-preguntas) → [final mock](/practica/simulacro-final). Optional [labs](/practica/labs-hands-on).
5. **Bridge to official prep** — [resources](/recursos): confirm specifics, then drill Skill Builder.

All practice questions are **original**; this course does not reproduce real exam items. It avoids inventing exact figures — where a number could drift, it flags "confirm in current AWS docs."
